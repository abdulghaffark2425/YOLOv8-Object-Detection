# Real-Time Object Detection using YOLOv8

This repository contains a Computer Vision project that utilizes **YOLOv8** and **OpenCV** to perform real-time object detection and frame analysis.

## Features
- Implements state-of-the-art YOLOv8 model for multi-class object detection.
- Fast inference speed suitable for real-time video feeds and image processing.
- Automatically labels detected objects and saves output images.

## Tech Stack
- **Language:** Python
- **Frameworks:** Ultralytics YOLOv8, PyTorch
- **Libraries:** OpenCV
